# Quarantined: Blink / Vite frontend (not part of EvalForge)

**Status:** quarantined. Not built, tested, or deployed by EvalForge CI. Not maintained.

## Provenance

These files arrived on `main` in commit `47a0d6d`
("[Blink] feat(index): Introduce AI assistant and device selection guide"),
generated by the Blink app builder. They implement an unrelated
"AI Download Guide" React/Vite/TanStack Router app and share no code, data, or
tests with EvalForge (Python/FastAPI, `app/`, `finance_eval/`).

They were moved here unchanged (history preserved via `git mv`) so the repository
root describes one product.

## What was removed rather than moved

| File | Reason |
|------|--------|
| `.gitattributes` | Forced Git LFS on all `*.png`, `*.jpg`, `*.pdf`, fonts, etc. repo-wide. EvalForge stores `docs/assets/*` screenshots as regular blobs, so this caused "should have been a pointer" warnings. |
| `.gitconfig` | Contained only `[safe] directory = /home/user` from the Blink sandbox. Git does not read a repo-root `.gitconfig`, so it had no effect. |

Both are recoverable with `git show 47a0d6d:<path>`.

## Notes

- `src/blink/client.ts` contains a Blink project ID and *publishable* key.
  Publishable keys are designed to ship to browsers, but the key should be rotated
  in the Blink dashboard if this app is no longer in use.
- To run it, move this directory to its own repository and run `bun install`
  (or `npm install`) there. EvalForge does not support this.
